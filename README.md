# Финальный проект 5 спринта  

В этом файле описаны фикстуры, тесты  и вспомогательный модуль data, который помогает с тестовыми данными.

## Фикстуры: 

**browser** 
Запускает браузер, открывает стартовую страницу. Адрес страницы в модуле data.


**new_user**
Регистрирует нового пользователя. На выходе иммем залогиненную стартовую страницу.


## Модуль data\data: 

Здесь хранится адрес стартовой страницы, креды для двух пользователей: один ранее зарегистрированный, второй - с некорректным емаил.


## Модуль data\helpers: 

Есть метод, который генерирует креды для нового пользователя: email и пароль. Получаем уникальные данные благодаря привязке к datetime.now().
Есть метод, который генерирует новый товар для размещения объяввления.


## Модуль data\locators: 

Описаны локаторы для элементов, задействованных в тестах.
